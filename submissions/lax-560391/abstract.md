This draft extends an overview and hierarchy of graph parameters by defining
ten further parameters:

- Boxicity
- c-closure
- Chordal intersection dimension
- Cochromatic number
- Distance to block graphs
- Distance to chordal graphs
- Distance to distance-hereditary graphs
- Distance to interval graphs
- Edge clique cover number
- Vertex integrity

Throughout, graphs are finite, simple, and undirected, and may be disconnected.
All ten parameters assign zero to the empty graph. Boxicity and chordal
intersection dimension allow zero dimensions and zero factors, respectively,
so complete graphs have value zero. The c-closure convention also assigns
zero to complete graphs.

The draft also defines the underlying structures and graph classes in
separate concepts:

- Edge clique covers
- Cochromatic partitions
- Box representations
- Interval representations
- Chordal intersection representations
- c-closed graphs
- Chordal graphs
- Block graphs
- Distance-hereditary graphs
- Interval graphs
